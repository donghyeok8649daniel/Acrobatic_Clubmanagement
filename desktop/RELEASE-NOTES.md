Windows 10/11 64비트용 아크로바틱 설치 프로그램입니다.

- `Acrobatic-Setup-0.1.0-x64.exe`를 실행하면 현재 Windows 사용자 계정에 설치되고 바탕화면·시작 메뉴에 아크로바틱이 추가됩니다.
- PC 앱과 온라인 사이트는 같은 서버와 팀 기록을 사용합니다. 팀 ID와 개인 입장코드로 로그인하세요.
- 인터넷 연결이 필요합니다. 훈련 영상 업로드는 운영 계정의 영상 저장소 연결 후 이용할 수 있습니다.
- Windows 코드 서명 인증서가 없는 초기 배포본입니다.
- SHA256SUMS.txt에서 설치 파일의 SHA-256 해시를 확인할 수 있습니다.
